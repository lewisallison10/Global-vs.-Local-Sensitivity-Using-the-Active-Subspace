# Global-vs.-Local-Sensitivity-Using-the-Active-Subspace
Sample code to accompany the paper "Using active subspaces to explore discrepancies between global and local parameter sensitivities in a Lotka-Volterra system", H. Zou and A.L. Lewis, 2026.

# TwoDimEx_SampleCode.m 
Contains code to generate subspace distances and activity scores for each of the three two-dimensional examples discussed in the manuscript.

# LotkaVolterraEx_SampleCode.m
Contains code to generate global and local active subspaces, activity scores, and subspace distances for the primary QoI.
